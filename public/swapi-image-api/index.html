SWAPI Images API — Free Images for The Star Wars API

SWAPI returns only JSON text — no pictures. This free API serves 238 images for SWAPI people, planets, species, starships and vehicles, using exactly the same IDs as SWAPI. No API key, CORS enabled.

URL pattern

https://starwarsgallery.netlify.app/assets/{category}/{id}.jpg

How to use it

JavaScript

const getSwapiImage = (category, swapiUrl) => {
  const id = swapiUrl.split('/').filter(Boolean).pop();
  return `https://starwarsgallery.netlify.app/assets/${category}/${id}.jpg`;
};

const res = await fetch('https://swapi.dev/api/people/1/');
const luke = await res.json();
const image = getSwapiImage('people', luke.url);
// "https://starwarsgallery.netlify.app/assets/people/1.jpg"

React (with fallback)

function SwapiImage({ category, id, name }) {
  const [src, setSrc] = React.useState(
    `https://starwarsgallery.netlify.app/assets/${category}/${id}.jpg`
  );
  return (
    <img
      src={src}
      alt={name}
      loading="lazy"
      onError={() => setSrc('/placeholder.jpg')}
    />
  );
}

Python

import requests

planet = requests.get("https://swapi.dev/api/planets/1/").json()
planet_id = planet["url"].rstrip("/").split("/")[-1]
image_url = f"https://starwarsgallery.netlify.app/assets/planets/{planet_id}.jpg"

Features

  • Same IDs as SWAPI — no mapping table needed.
  • CORS enabled (Access-Control-Allow-Origin: *) — works with fetch(), <img>, <canvas> and mobile apps.
  • No API key and no sign-up.
  • Real HTTP 404 for missing images, so onError fallbacks work.
  • Fast static CDN hosting with browser caching.
  • Live production example: integrated in Star Wars App for character and starship visual cards.
  • A drop-in alternative for projects that used the old starwars-visualguide.com image URLs.

FAQ

Does SWAPI provide images?

No. SWAPI only returns JSON. This API fills that gap using the same resource IDs.

What if an ID has no image?

The server returns 404. Check images.json for the list of available IDs.

Can I use it in commercial projects?

The API is free for personal, educational and portfolio projects. See the terms below.
